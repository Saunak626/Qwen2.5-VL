# 模型预测结果准确性分析工具

## 功能概述

`analyze_predictions.py` 是一个用于分析模型预测结果准确性的Python脚本,主要功能包括:

1. **数据对齐验证**: 验证预测结果与数据集样本的一一对应关系
2. **视频级别错误分析**: 按视频来源分组统计预测准确率
3. **统计指标计算**: 计算每个视频和整体的准确率、正确数、错误数等指标
4. **结果导出**: 支持将统计结果导出为CSV文件

## 使用方法

### 基本用法

使用默认路径运行分析:

```bash
python3 analyze_predictions.py
```

默认路径:
- 预测结果: `LLaMA-Factory/saves/Qwen2.5-VL-7B-Instruct/lora/eval_2025-09-20-23-50-43/generated_predictions.jsonl`
- 数据集: `LLaMA-Factory/data/subj_multi_test_data.json`

### 指定自定义路径

```bash
python3 analyze_predictions.py \
  --predictions path/to/your/predictions.jsonl \
  --dataset path/to/your/dataset.json
```

### 保存结果到CSV文件

```bash
python3 analyze_predictions.py --output results.csv
```

### 查看帮助信息

```bash
python3 analyze_predictions.py --help
```

## 输入文件格式

### 预测结果文件 (JSONL格式)

每行一个JSON对象,包含以下字段:
- `prompt`: 输入提示词
- `predict`: 模型预测结果
- `label`: 真实标签

示例:
```json
{"prompt": "...", "predict": "微饿", "label": "微饿\n"}
```

### 数据集文件 (JSON格式)

JSON数组,每个元素包含:
- `messages`: 对话消息列表
  - `messages[0]`: 用户消息
  - `messages[1]`: 助手消息(包含真实标签)
- `videos`: 视频路径列表

示例:
```json
[
  {
    "messages": [
      {"content": "...", "role": "user"},
      {"content": "微饿", "role": "assistant"}
    ],
    "videos": ["/path/to/video_clips/240717(9.03.26）_clip_300.mp4"]
  }
]
```

## 视频标识符提取规则

脚本会从视频路径中自动提取视频标识符:

- 输入: `/home/swq/Code/.../video_clips/240717(9.03.26）_clip_300.mp4`
- 输出: `240717(9.03.26）`

提取规则:
1. 提取文件名部分
2. 使用正则表达式匹配 `_clip_` 之前的部分
3. 去掉 `_clip_XXX.mp4` 后缀

## 错误处理

脚本包含以下错误处理机制:

1. **文件不存在检查**: 如果指定的文件不存在,会抛出 `FileNotFoundError`
2. **样本数量不匹配警告**: 如果预测结果和数据集样本数量不一致,会显示警告并只分析较小数量的样本
3. **标签不一致警告**: 如果预测文件中的标签与数据集中的标签不一致,会显示警告(最多显示前5个)
4. **JSON解析错误**: 如果JSON格式错误,会显示具体的错误信息

## 依赖项

- `argparse`: 命令行参数解析
- `re`: 正则表达式

- `collections`: 数据结构

1. 脚本假设预测结果和数据集按相同顺序排列
2. 标签对比时会自动去除空白字符(包括换行符)
